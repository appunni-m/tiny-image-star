# Tiny Image Star

Tiny Image Star is a local-first visual design editor. It provides pages and nested layers, a canvas workspace with layer and property panels, and a responsive mobile layout with slide-in side panels. Design documents and image sources stay in the current browser profile on this device.

The editor supports editable vector paths and graph-backed Pen networks with shared junctions, branching strokes, closed fill regions with independent color and opacity, per-edge Bézier handles, curve-preserving point insertion, and topology-aware point deletion. Networks can be used as live Boolean operands and alpha masks. Other features include layer grouping and ungrouping, bounds-aware multi-selection alignment and distribution, copy/cut/paste/duplicate layer actions with undo and redo, live non-destructive Boolean groups, editable alpha-mask groups, solid, linear, and radial fills with editable color stops, clipped image fills with Fill/Fit scaling and local Pillow-RS adjustments, 16 layer blend modes, drop shadows and layer blur, and text boxes with fixed-size, auto-height, and auto-width behavior, editable system font families, the 100–900 weight scale, italic styling, text case, and underline or strikethrough. Text can be selected and formatted inline with bold, italic, font family, weight, size, letter spacing, decoration, and color controls; mixed run styles affect layout, rendering, and SVG export. Reusable text styles snapshot font family, size, weight, style, line height, letter spacing, alignment, color, case, and decoration; they can be applied to selected text or updated for future use. The editor also supports selection and transforms, multi-select, horizontal and vertical auto layout, grid auto layout with independent row and column gaps, manual cell placement and spans, per-layer minimum and maximum sizing in auto layout, responsive frame constraints, frame layout guides, and an outline view. The Inspect panel shows resolved layer values and provides copyable nested HTML scaffolding, CSS, and exact local layer JSON. It also supports linked components, instances and variant sets, reusable color styles, and typed variables with per-mode aliases and frame-level theme overrides. Variable bindings can drive paint, text, font size, line height, letter spacing, opacity, radius, and visibility. Local images are placed and edited through Pillow-RS WebAssembly; previews always render from the original image held in memory, so adjustments do not compound. Image fills reference those same local image sources and remain editable after reload or `.flocal` export. Saved image recipes can be applied to a multi-selection from the canvas or Layers panel using an in-place batch bar with pause, cancel, progress, and worker controls. Local design files can be imported and exported as `.flocal` packages. SVG export preserves editable vector shapes and text, embeds local raster layers and unadjusted image fills, and supports solid, linear, and radial shape fills, drop shadows, layer blur, and blend modes. Unsupported content—including adjusted raster images, masks, Boolean layers, and unsupported gradient placements—is rejected with a specific message rather than silently omitted.

Prototype interactions can connect layers to frames with click/tap or hover triggers, set a starting point, configure transitions including Smart Animate with linear, ease-in, ease-out, or ease-in-out timing, open centered or edge-positioned overlays, dim the presentation background, dismiss overlays from their own interactions or outside clicks, and move back through overlay and navigation history. Smart Animate matches layers by name and parent hierarchy, interpolates geometry, opacity, numeric text metrics, and compatible solid colors, and switches categorical text and paint styles at the midpoint. These links are stored with the local document.

Canvas comments support anchored review threads, replies, resolution, and deletion. Threads are saved inside the local design file and included in `.flocal` exports; they do not sync between devices.

This is an active rebuild, not production certification or complete parity with mature collaborative design tools. Boolean previews use a bounded-resolution local canvas composite while keeping their source vectors editable. Linked component instances retain local property, geometry, and child-order overrides while main component structure and styling synchronize. Component sets support named variant properties, per-instance variant switching, and override migration across structurally matching layers. Areas still under development include advanced vector operations, variable bindings for layout behavior beyond position, size, and rotation, additional rich-text controls and richer layout behavior, additional prototype actions and wider Smart Animate property parity, cross-device comment sync and multiplayer, framework-specific developer handoff, proprietary design-file import, and SVG preservation for raster adjustments, vector networks, masks, Boolean layers, and unsupported gradient placements. Tiny Image Star does not claim compatibility with third-party project files or cloud services.

## Run locally

```sh
npm run dev
```

Open `http://127.0.0.1:8000`. The app does not upload image or design data. The local server sends cross-origin isolation headers needed by WebAssembly workers.

## Verify

```sh
npm test
npm run verify:static
```

With the server running, open `http://127.0.0.1:8000/tests/browser-smoke.html` to run the browser workflow smoke. It exercises image previews and recipes, image-fill editing and portable reload, layer blend-mode rendering, text fonts and reusable styles, local packages, components and variants, vector editing, grouping and alignment, variables, grid auto layout, Boolean operations, gradients and layer effects, prototype presentation, masks, and mobile Layers touch targets. Open `http://127.0.0.1:8000/tests/mobile-recipe-smoke.html` to verify saving a recipe from one image and applying it to a touch-selected batch without keyboard modifiers or context menus, including reachable live speed and pause controls. Open `http://127.0.0.1:8000/tests/rich-text-editing-smoke.html` to verify phone-sized bold, italic, size, and color range formatting, saved-run reload, reopen, continued editing, and plain-text behavior. Open `http://127.0.0.1:8000/tests/mask-smoke.html` to verify editable mask creation and release through the Layers context menu and Layer options menu, `http://127.0.0.1:8000/tests/export-smoke.html` to verify mobile-ready raster settings plus selected-layer and page SVG downloads, `http://127.0.0.1:8000/tests/guides-smoke.html` to verify frame guides and mobile controls, `http://127.0.0.1:8000/tests/outline-smoke.html` to verify outline mode, `http://127.0.0.1:8000/tests/inspect-smoke.html` to verify text sizing, case and decoration controls, editable gradients and effects, nested HTML/CSS and JSON handoff, clipboard actions, and phone-sized controls, or `http://127.0.0.1:8000/tests/comments-smoke.html` to verify canvas comments, replies, resolution, local persistence, and phone controls.
