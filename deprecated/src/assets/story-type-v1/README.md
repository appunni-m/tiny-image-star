# Story typography pack, revision 1

These are unmodified font binaries distributed under SIL Open Font License 1.1.
The exact source revision, original URLs, sizes and hashes are in
[provenance.json](provenance.json). The variable axes, font version strings and
character counts inspected with fontTools 4.60.2 are in
[inspection.json](inspection.json).

| Typeface | Intended use | Original license |
| --- | --- | --- |
| Source Serif 4 | Scrapbook and closing captions | [Adobe copyright and OFL](sourceserif4/OFL.txt) |
| Source Sans 3 | Quiet captions | [Adobe copyright and OFL](sourcesans3/OFL.txt) |
| Source Code Pro | Film diary and page numbers | [Adobe copyright and OFL](sourcecodepro/OFL.txt) |
| Oswald | Depth cover title | [Oswald Project copyright and OFL](oswald/OFL.txt) |

All four binaries total 2,240,276 bytes. A recipe uses only its declared fonts;
the library may load other compatible recipes for their visible previews.
Fonts load from the application origin, with exact-length and SHA-256 checks.
They are stored with saved projects. No Google Fonts stylesheet or font CDN is
contacted at runtime. Choose device fonts if a font cannot be loaded or lacks a
needed character. Device font appearance varies between platforms.

Files are copied unchanged into the static artifact. Font family names used
internally by the browser do not alter the binaries. The original reserved font
names, copyrights and license texts remain in their accompanying files.
Character coverage comes from each binary's Unicode cmap; it does not establish
cross-browser shaping quality or a complete multilingual typography review.
